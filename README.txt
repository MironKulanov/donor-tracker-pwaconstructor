ДОНОРТРЕКЕР — iPhone PWA

Содержимое:
- index.html — приложение на основе исходного файла.
- manifest.json — настройки установки PWA.
- service-worker.js — кэширование приложения и ресурсов для офлайн-работы.
- icons/ — иконки.

ВАЖНО ОБ ОФЛАЙНЕ:
Текущий исходный HTML использует Tailwind CSS, Lucide и шрифт Inter с внешних CDN.
Service Worker кэширует эти ресурсы при первой загрузке под своим контролем, чтобы затем
попытаться отдавать их без сети. Поэтому после первой публикации нужно открыть приложение
онлайн, дождаться загрузки, обновить страницу ещё раз онлайн и только затем проверять
авиарежим. Это промежуточная реализация: для гарантированной независимости от CDN нужно
в следующем этапе встроить/положить локально CSS, иконки и шрифт и проверить офлайн.

Данные донаций сохраняются в localStorage браузерного приложения на устройстве.
Не очищайте данные Safari/сайта. Регулярно используйте экспорт резервной копии.

Публикация: GitHub Pages из корня ветки main.
На iPhone: открыть опубликованный HTTPS-адрес в Safari > Поделиться > На экран Домой.
